## 실패·미지급 진단

실패 구간은 실패 직전까지 마지막으로 실제 착지가 확인된 보상 구간이다.

```json
{
  "failures": {
    "얼음 바다로 떨어졌어요": 100
  },
  "failure_regions": {
    "층 전환": 99,
    "아래 점프": 1
  },
  "unpaid_landings": {},
  "duplicate_landings": {
    "02-exit": 99,
    "03-exit": 99,
    "04-first": 99,
    "04-exit": 198,
    "turn-first": 3
  }
}
```

중복 착지 수는 이미 지급한 항목의 대상 발판에 다시 착지한 횟수이며 중복 지급이 아니다.
착지율이 높고 지급률이 낮다면 직전 발판 연결 또는 리프트 접촉 높이 조건을 확인한다.
학습 지표와 코드 검사는 완주 보장을 의미하지 않는다. 단일 시드 결과만으로 일반적인 우열을 단정하지 않는다.
