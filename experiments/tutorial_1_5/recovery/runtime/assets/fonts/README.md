Source: https://github.com/google/fonts/tree/133ccbee9a8b408eb71f31a36ccb9116f5c695ad/ofl/nanumgothic

SHA-256:

- NanumGothic-Regular.ttf: `76f45ef4a6bcff344c837c95a7dcc26e017e38b5846d5ae0cdcb5b86be2e2d31`
- NanumGothic-Bold.ttf: `f96298f9fb18e364d2370f4c3ce948ac67a2b61af992d7234bc15c42b033c674`

The game prefers the existing Malgun Gothic on Windows. Elsewhere it uses
these bundled fonts, so Korean UI labels do not depend on installed fonts.
