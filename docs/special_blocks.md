# 특수블록 37종

첨부된 「특수 블록 기능 한눈에 · 시안 A」의 번호를 엔진의 `Device.type_id`로 사용합니다.
일반 게임의 **스테이지 선택 → 특수블록 실험실**에서 각 방에 들어갑니다.
`special_blocks_play.bat`를 실행하거나 `python main.py --lab`로 바로 열 수 있습니다.
`python main.py --special 405`처럼 번호로 직접 진입할 수도 있습니다.
실험실은 기존 캠페인 해금이나 최고 기록을 저장하지 않습니다.

## 조작과 연결

좌우 방향키로 이동하고, 착지하거나 접촉하면 해당 장치가 작동합니다. R은 방 전체를
초기화합니다. 일시정지하면 발판·위험물·발사체·타이머도 함께 멈춥니다.
스위치·자석·시프트는 공 전체가 가로 영역 밖으로 나간 뒤 재착지해야 재작동합니다.
4/8방향 슈터는 `options.direction`으로 방향을 고정하거나, 생략하면 재착지마다 방향을
한 칸씩 순환합니다. 일반 방향키 입력이나 벽 충돌로 발사를 해제합니다.

장치의 `group`은 연결 채널입니다. 투명 스위치·별 스위치·장벽·투명 블록은 같은 채널의
상태를 공유합니다. 전원은 `power:<group>` 채널을 켜고 끕니다. 연결 장치에는 같은
`group` 또는 `options.power_group`을 설정합니다. 510 전기 블록은 전원과 관계없이
고체이며 접촉 자체는 비치명입니다. 자석·시프트는 `target` ID나 동일 `group`의
발판을 대상으로 삼습니다. 자석은 지정 반경 안에서만 움직입니다.

306의 지연은 첫 접촉부터 진행되며, 켜진 위험 상태는 재시작까지 유지됩니다.
빨강이 켜진 뒤에는 다시 닿으면 실패하고, 파랑은 0.15초 간격으로 재반발할 수 있습니다.
전송 출구가 고체나 화면 밖이면 전송하지 않고 `teleport_blocked` 이벤트를 반환합니다.
짝이 없는 포털은 비활성입니다. 단검의 기본 경계는 전체 화면이며, 벽 단검의 기본
사각 경로는 원래 위치에서 128×128px입니다.

수치가 원본 표에 없는 항목은 위 기본값을 적용했습니다. 모두 맵 데이터에서 조절할 수
있으며 기존 캠페인의 물리 설정은 바꾸지 않습니다. 37종 모두 종류별 실험실에서 제공하고,
기존 캠페인 지형을 임의로 교체하지 않습니다. 검증판 맵09의 발자국 발판은 307 가속으로
연결했습니다. 그 맵의 기존 클리어 경로는 가속 발판 없이도 통과합니다.

## 맵 작성 예

```python
from pingu_ball.specials import Device

level.specials = [
    Device('power', 404, 256, 640, group='A'),
    Device('cannon', 603, 768, 576, group='A', options={'period': 1.2}),
    Device('switch', 415, 384, 640, group='bridge'),
    Device('bridge', 416, 512, 640, group='bridge'),
    Device('door-in', 410, 128, 512, group='doors'),
    Device('door-out', 410, 1024, 256, group='doors'),
]
```

`World.reset()`는 원래 맵 데이터에서 장치 상태·위치·타이머·발사체를 모두 복원합니다.
센서/레이저/발사체는 물리 엔진의 연속 충돌 후보로 들어가며 실패 판정은 수집·도착보다
우선합니다. 회전 위험물은 프레임률과 무관한 물리 시간으로 움직이고, 레이저 끝의 이동량이
서브스텝당 2px 이하가 되도록 추가 분할하여 시작·중간·끝 각도를 검사합니다.
그림에 사용한 다각형과 충돌 다각형은 같습니다. 학습 환경의 `specials`, `projectiles`
관측에도 연결·타이머·충돌 위치가 JSON 데이터로 제공됩니다.
