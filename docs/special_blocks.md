# 튜토리얼 스테이지

「튜토리얼 스테이지.docx」의 맵 10개를 실제 게임 지형으로 재구성합니다. 기존 체험 맵 37개,
옛 기본 조작 튜토리얼과 비활성 이미지 맵 50개는 제거했습니다. 일반 스테이지 1~7은 유지합니다.

| 번호 | 맵 | 구성과 동작 |
|---|---|---|
| 1 | 파괴 블록 | 기본 발판 사이의 파괴 블록 4개. 밟으면 즉시 사라지며 반동은 유지 |
| 2 | 점프 블록 | 상승하는 발판 4묶음. 일반 반동 96px, 점프 블록 144px에 맞춘 높이 간격 |
| 3 | 이동 블록 좌우 | 가시 계단 위의 3칸 이동 발판. 연결 발판이 같은 위상으로 왕복 |
| 4 | 이동 블록 상하 | 한 칸짜리 발판이 y=256~448 사이를 왕복. 상단 기본 발판으로 이동 |
| 5 | 시간 블록 | 개별 위상을 가진 3개 블록. 활성·경고·반투명 상태를 반복 |
| 6 | 좌우 발사 블록 | 상단에서 하강하여 왼쪽 화살표를 밟고 왼쪽 이글루로 발사 |
| 7 | 태양 블록 | 사각 64px 판정의 비고체 태양 5개. 마지막 점프 발판으로 높은 태양을 회피 |
| 8 | 고드름 | 위에서 생성·낙하. 생성 중 0.5초는 안전하고 이후 접촉 치명. 주기적으로 재생성 |
| 9 | 바다사자 | 두 개의 3칸 발판 둘레를 순환. 크기 56px, 변 방향에 맞춰 90도 회전 |
| 10 | 점프와 대시 아이템 | 점프로 128px 높은 발판에 오른 뒤 대시로 5칸 빈 구간을 통과. 아래 우회로 없음 |

기본·파괴·점프·시간·이동·발사 발판의 논리 크기는 64×64px입니다. 공은 28px이며
시작 위치는 바닥 윗면보다 공 중심이 110px 높은 일반 반동 최고점입니다. 이동 발판에
착지해도 발판의 이동량이나 속도를 공에 더하지 않습니다. 가시는 기본 블록의 눈을 덮도록
22px 겹쳐 표시합니다. 쌓인 기본 블록은 맨 위에만 눈을 표시합니다.

시간 블록은 스테이지 시간과 함께 시작해 미리 정한 주기를 반복하며, 비활성 상태에도
반투명 이미지가 남습니다. 재시작하면 시간·발판·위험물·아이템이 초기화됩니다.

태양은 빈 공간의 위험물이며 발판이 아닙니다. 고드름은 생성 시점부터 0.5초가 지난 뒤
중력으로 낙하하며 공에 닿으면 실패합니다. 주기가 끝날 때 위로 순간 이동하는 경로는
충돌 궤적으로 처리하지 않습니다. 바다사자는 블록보다 작은 전체 이미지 중 바깥으로
나온 절반만 충돌하며, 지형 뒤에 먼저 그려 몸 일부가 가려지도록 합니다.

점프 아이템은 노랑 결정과 위쪽 이중 화살표, 대시는 청록 결정과 오른쪽 이중 화살표입니다.
획득한 종류에 따라 공 색과 테두리가 바뀝니다. 점프는 ↑↑, 대시는 ←← 또는 →→,
마우스·터치는 같은 위치를 0.3초 이내 두 번 누릅니다. 각각 한 번 사용하고 재시작하면 복구합니다.

## 실행과 기록

`python main.py --lab`으로 전체 목록, `python main.py --special 1`~`10`으로 특정 맵을 엽니다.
1~10번 최고 시간은 저장 파일의 `tutorial_records`에 기록합니다. 기존 일반 스테이지 기록은
유지하며, 튜토리얼을 한 개 클리어하면 일반 스테이지 1번을 열 수 있습니다. 학습 API의
`make_level(0)`은 별도의 옛 기본 맵이 아니라 새 튜토리얼 1번을 반환합니다.

## 검증

`python tools/verify_tutorials.py`는 실제 엔진에 이동·아이템 입력을 재생하여 10개 맵의 도착을
검증합니다. `--stage 10`처럼 특정 맵만 실행할 수 있습니다. 입력 기록과 결과는
`output/tutorial-validation/`에 저장합니다. `python tools/render_tutorials.py`는 현재 실제 맵과
튜토리얼 목록을 같은 폴더의 PNG로 생성합니다. 문서 시안과 실제 플레이 화면을 구분합니다.
