# Pingu Ball 요구사항 대응표

기획서의 게임 규칙을 구현하고, 상충하거나 미정인 항목은 README의 적용 기준으로 구분했다. 왕복 발판의 독립 이동은 사용자에게 확인한 결정이다.

| 기획서 요구사항 | 구현 | 검증 |
|---|---|---|
| Pygame 게임 이름 Pingu Ball | app.py 창 제목·메뉴, main.py | 메뉴·플레이 렌더링 |
| 20×20 블록, 반지름4.5 공 | config.py, engine.py | 공간 설정·충돌 테스트 |
| 기본60, 점프대90 높이 | 유도된 반동 속도 적용 | normal_free_flight, pad_free_flight |
| 기본240, 정지225, 점프대293.94 거리 | 고정 중력·수평 가속 | 자유 비행·가속 테스트 |
| 공중 좌우 가속·감속 | advance_x, World.step | acceleration, release_deceleration |
| 별도 점프 키 없음 | 착지 이벤트 자동 반동 | landing_replaces_fall_speed |
| 왕복 발판은 공과 독립 이동 | rect_at 왕복 위치, 속도 비전달 | moving_block_does_not_carry_airborne_ball |
| 윗면만 반동, 벽·천장 보정 | 연속 원형 충돌과 법선 | side_collision, ceiling_stops_ascent |
| 빠른 이동 중 관통 방지 | sweep_circle_rect / polygon | fast_ball_does_not_pass_through_wall |
| 플러스3·마이너스1, 공중 배치 | levels.py, 중심점14×14 센서 | collectible_counts, collectibles_use_center |
| 플러스는 생선, 마이너스는 생선 가시 | 같은14px 표시 크기, 색·형태 구분 | 실제 화면 확인 |
| 도전당 한 번 획득 | collected 인덱스 집합 | collectibles_use_center |
| 기본7점과 B~SSS | World.score, World.grade | 점수·기록 테스트 |
| 튜토리얼 선택 수집1개·등급 없음 | level0, score=None 저장 | tutorial_has_no_grade_or_score |
| 모든 맵 무수집·10점 경로 | 낮은 경로와 높은 선택 경로 | 16개 실제 물리 입력 경로 |
| 깨지는 블록0.5초, 떠나도 유지 | 착지 시 break_at 저장 | breakable_delay_and_reset |
| 시간 블록 주기·위치 윤곽·점멸 | Platform.active, app.tile | timed_period, pause, 화면 확인 |
| 시간 블록 생성 압착 실패 | 생성 상태 비교와 겹침 해소 | timed_spawn_unresolvable_crush_fails |
| 스위치 활성·재진입 시 비활성 | armed와 연결 group 상태 | switch_does_not_toggle_on_every_bounce |
| 수평 발사·입력 해제·중력 재개 | Ball.launch와 발사 원점 재작동 방지 | launcher_and_input_release |
| 가시 접촉·하단 이탈 실패 | 삼각형 연속 검사, 하단 판정 | spike_contact_wins_over_goal |
| 실패·R 재시작 시 도전 상태 복구 | World.reset | fail_resets_all_transient_state |
| 기록·해금 유지와 다음 해금 | Progress.complete 원자 저장 | best_score_then_time_and_unlock |
| 낮은 점수·느린 동점으로 기록 덮어쓰기 방지 | 점수 우선, 시간 보조 비교 | best_score_then_time_and_unlock |
| 화면 없는 반복 실행 | Pygame 독립 World와 validate | unittest·경로 CLI |
| 전체 맵 한 화면,2:1 비율 | 1200×600 논리 화면·레터박스 | 창 크기 변경과 버튼 검사 |
| FPS와 물리 시간 분리 | 누적 시간과120Hz 갱신 | render_fps_does_not_change_fixed_tick_simulation |
| 일시정지 시 물리·타이머 정지 | World.paused, App accumulator 비우기 | first_input_and_pause_freeze_everything |
| 선택·결과·재도전·다음 스테이지 | 메뉴 카드·결과 모달·완주 화면 | UI 상태 전이 검사 |
| 실패→획득→도착 우선순위 | 시각이 같은 이벤트 우선순위 | spike_contact_wins_over_goal, simultaneous_fish_before_goal |
| 기본 낙하 속도와 관계없는 반동 | 착지 시 고정 반동 속도 | landing_replaces_fall_speed |
| 중력 반전은 확장 후보 | 현재 구현 범위에서 제외 | README에 범위 구분 |

일반맵7개 및 튜토리얼은 예시 그림을 그대로 충돌 맵으로 사용하지 않고, 실제 물리 경로를 검증할 수 있는 플랫폼 데이터로 구성했다. 높은 선택 경로의 수집물은 낮은 기본 경로의 반동만으로 우연히 획득되지 않도록 분리했다.
