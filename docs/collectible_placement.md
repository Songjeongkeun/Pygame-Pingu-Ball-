# 일반 스테이지 생선 배치

사용자가 승인한 배치 재검토안 2의 중심 좌표를 그대로 적용했다. 각 맵은 금색 생선 3개(+1점)와 생선뼈 1개(-1점)를 가진다. 튜토리얼은 기존대로 생선을 배치하지 않는다.

제공된 투명 PNG 두 개를 사용하며 맵의 생선·생선뼈는 모두 64×48px로 표시한다. 공 중심이 진입하는 수집 영역도 64×48px이며 중심 좌표는 유지한다. 상단 획득 개수 표시의 작은 아이콘은 기존 비율을 유지한다. 한 번 획득한 수집물은 사라지고 재시작 시 복구된다. 기본점수는 7점이다. 생선만 3개 획득하면 10점, 생선뼈까지 획득하면 9점이다.

파괴 블록과 겹친 수집물은 의도된 배치다. 4번 생선뼈 B1은 (224,800)에 그대로 두며, 블록을 깨기 전에는 진입할 수 없고 파괴 후 같은 자리에서 획득한다. 9번 B1도 (424,768)의 승인 위치를 유지한다.
