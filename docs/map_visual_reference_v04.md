# 맵 제작 이미지 기준

사용자가 2026년 10월 20일 지정한 블록·장애물 10종과 아이템 2종의 외형 기준이다.
기준 원본: [블록과 아이템 이미지](../assets/references/map_block_catalog_v04_01.png).
앞으로 맵 이미지를 생성할 때 이 원본을 직접 참조한다. 이전에 생성한 맵의 임의 외형보다 이 기준을 우선한다.

| 번호 | 요소 | 이미지에서 유지할 특징 |
|---|---|---|
| 01 | 파괴 블록 | 눈 덮인 파란 얼음과 뚜렷하게 금이 간 외형. 한 번 밟으면 사라지는 블록이며 시계 표시를 넣지 않는다. |
| 02 | 점프 블록 | 주황색 위쪽 화살표. 일반 점프 높이의 1.5배. |
| 03 | 좌우 이동 블록 | 청록색 좌우 양방향 화살표 ↔. |
| 04 | 상하 이동 블록 | 청록색 위아래 양방향 화살표 ↕. |
| 05 | 시간 블록 | 시계가 있는 활성·경고·비활성 3가지 모습. 비활성은 반투명하며 파괴 블록과 혼동하지 않는다. |
| 06 | 가시 블록 | 기본 발판 위에 밀착한 뾰족한 얼음 가시. |
| 07 | 좌우 발사 블록 | 주황색 불꽃 모양의 왼쪽 또는 오른쪽 화살표. 이동 블록의 청록색 양방향 화살표와 구별한다. |
| 08 | 태양 | 노란 중심과 주황색 불꽃의 태양. 기존 감전기 외형을 대체한다. |
| 09 | 고드름 | 아래로 뾰족하게 늘어진 얼음. 기존 낙석 외형을 대체한다. |
| 10 | 바다사자 | 원본의 파랑·회색 바다사자 캐릭터. 기존 블록 표창 외형을 대체한다. |

| 아이템 | 획득 전 | 획득 후 공 |
|---|---|---|
| 대시 | 청록색 얼음 결정과 » 기호 | 검은색 공과 청록색 테두리 |
| 점프 | 호박색·금색 얼음 결정과 ↑↑ 기호 | 갈색 공과 금색 테두리 |

맵 작업 시에는 요청받은 원본 배치와 블록 종류를 유지한다. 위 외형을 임의로 다른 블록의 모습으로 바꾸지 않는다.
별 삭제나 이글루 위치 변경은 해당 맵에 대한 사용자 지시에 따른다.
이 문서와 원본 저장은 향후 이미지 제작의 기준을 남기는 작업이며, 현재 게임 코드나 아이템 외형을 즉시 교체하는 작업은 아니다.
