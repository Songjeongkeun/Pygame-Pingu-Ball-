# 일반 스테이지 완주 검증

2026년 10월 20일 기준으로 12개 일반 맵을 점검했다. 5번 점프 발판과 6번 이동 발판의 높이를 조정한 배치에서
11개 맵은 완주 입력을 확보했다. 8번은 왼쪽 이동·점프·파괴 다리 구간을 별도로 검증했고 전체 완주는 미확인이다.
이는 미확인 맵의 모든 우회 경로가 불가능하다는 수학적 증명은 아니다.

검증기는 게임과 같은 120Hz `World.step`에서 좌우 입력과 보유 아이템 사용 입력만 기록한다.
모든 성공 기록은 실제 시작점에서 출발하며, 새 월드를 만든 뒤 같은 입력을 다시 재생해
실패 0회와 이글루 도착을 확인한다. 공의 위치를 옮기거나 아이템을 지급하거나 장애물을 제거하지 않는다.
시간은 해당 검증 경로의 기록이며 최단 시간은 아니다. 별·생선의 추후 배치나 모든 출발 시점의
난이도를 검증한 결과는 아니다. 12번은 시작점 근처 발사 블록 두 개를 사용하는 짧은 우회 경로가 있다.

## 5번 수정

점프 블록을 아래부터 y=832·704·576·448·320px에 놓아 높이 차이를 각각 128px로 맞췄다.
위쪽 발사 블록에 도달하도록 점프 발판 2개를 추가했으며, 일반 반동 96px와 점프 반동 144px는 유지한다.
이글루와 점프 블록 사이 중앙 벽의 한 칸 빈자리(x=960, y=448px)는 기본 블록으로 채웠다.
시작점부터 오른쪽 발사 구간, 하단 파괴 발판, 점프 발판 다섯 개와 위쪽 발사 블록을 거친다.
발사 후 긴 가시 다리 왼쪽으로 내려가 시간 발판 네 개를 건너 이글루까지 완주한다.
시간 발판에 맞춰 출발 발판에서 세 번 더 튕긴 뒤 이동하며, 기존 장치의 ID와 시간 위상은 유지한다.
회귀 검증은 중간 발판을 이전 높이로 되돌리거나 새 발판 두 개를 제거한 월드에서 같은 입력으로
위쪽 발사 블록에 도달하지 못하고 완주되지 않는 것도 확인한다.

## 6번 수정

이동 발판 두 칸과 범위 표시를 y=640에서 704px로 내려 오른쪽 점프 블록(y=832px)과의 높이 차이를
128px로 줄였다. 왕복 거리 896px, 이동 속도 96px/s와 점프 반동 144px는 유지한다.
오른쪽 이글루는 y=448px, 그 아래 기본 발판은 y=512px로 올려 이동 발판에서 바로 도착할 수 없게 했다.
왼쪽 점프 블록(y=640px)에서 기본 발판(y=512px), 발사 블록(y=448px)으로 올라가는 경로를 맞췄다.
발사 높이 y=480px가 이글루 내부를 지나며, 이동 발판 위의 가로 안내선은 제거하고 투명 범위 표시는 유지한다.
시작 발판에서 두 번 더 튕긴 뒤 파괴 발판과 아래 발사 블록을 거쳐 오른쪽으로 이동한다.
오른쪽 점프 블록에서 이동 발판이 돌아올 때까지 기다린 뒤 올라타고 왼쪽 점프 블록으로 돌아간다.
기본 발판과 왼쪽 발사 블록을 거쳐 이글루로 발사된다.
이전 이동 발판 높이로 되돌리거나 위쪽 발사 블록을 제거하면 같은 입력으로 완주할 수 없음을 확인한다.

## 11번 수정

왼쪽 위 점프 블록을 (384,640px)로 내려 아래 점프 블록(256,768px)과 128px 차이로 맞췄다.
중앙 점프 블록은 (640,704px)로 올려 상단 기본 발판(y=576px)에 128px를 오르면 닿는다.
오른쪽 기본 발판 하나는 (1216,704px)로 옮겨 64px 간격의 복귀 경로를 만들었다.
시작 지점 아래 빈칸(1408,576px)은 기본 블록으로 채웠다. 바로 오른쪽의 상단 블록은
(1344,576px)의 계단에 놓고, 상단 빈칸(1472,512px)에도 기본 블록을 추가해 시작점에서
이글루로 바로 내려가는 길을 막았다. 일반 반동 96px와 점프 반동 144px는 유지한다.

실제 시작점에서 한 번 더 튕겨 바다사자의 위치에 맞춘 뒤, 오른쪽과 중앙의 파괴 블록을
아래 칸까지 제거하고 중앙 점프 블록과 상단 발판을 거친다. 첫 점프 아이템으로 왼쪽 파괴 기둥을
위에서부터 내려온다. 아래 점프 블록과 위 점프 블록을 거쳐 두 번째 점프 아이템으로 왼쪽 위에
돌아간 뒤, 태양 사이로 내려가 발사 블록을 타면 이글루까지 28.2532초에 실패 없이 완주한다.
공을 옮기거나 아이템을 지급하지 않는다. 점프 높이 회귀 검사와, 상단 빈칸을 열었을 때만
시작점에서 오른쪽으로 바로 내려가 클리어되는 비교 검사도 수행한다.

## 12번 수정

왼쪽 점프 블록(832,800px)을 (832,736px)로 64px 올렸다. 옆에 있는 네 점프 블록의 y=736px와
같은 높이이며 반동과 나머지 배치는 유지한다. 시작점에서 두 발사 블록을 거치는 기존 완주 입력도 재생한다.

## 추가 점검이 필요한 구간

- 8번: 좌우 이동 발판의 가로 범위를 x=192~704px, y=832px로 지정했다. 위쪽 왼쪽 점프 블록을
  y=576에서 640px로 내려 아래 점프 블록(y=768px)과의 차이를 128px로 맞췄다.
  점프 블록과 파괴 다리를 잇기 위해 첫 두 파괴 블록을 y=512·448px로 내렸다. y=640px의 점프 블록에서
  첫 파괴 블록으로 128px, 이후 y=384px 다리까지 64px씩 올라간다. 발판 수와 반동은 유지한다.
  `tools/verify_stage8.py`로 실제 시작점부터 이동·점프 발판을 거쳐 파괴 다리 7개를 모두 밟는 구간까지
  28.4833초에 실패 없이 도달했다. 아이템은 사용하지 않는다. 이전 이동 범위·점프 높이·파괴 다리 높이 중
  하나를 되돌리면 같은 입력으로 다리를 통과하지 못한다.
  오른쪽 상하 이동 발판의 실제 범위는 y=192~896px이며, 이글루까지 전체 완주는 미확인이다.

## 재현

```powershell
.\.venv\Scripts\python.exe -B tools/verify_campaign_routes.py
.\.venv\Scripts\python.exe -B tools/verify_campaign_routes.py --stage 5
```

`output/campaign-routes/report.json`은 전체 결과, `inputs_번호.json`은 성공한 맵의 틱별 입력,
`source_hashes.json`은 검증 당시 코드와 배치의 해시다. 전체 검사에서는 미확인 맵이 있어 종료 코드 1을 반환한다.
도착 센서만 검사하는 기본 로딩 검사를 전체 완주 검증으로 해석하지 않는다.
