# 승인된 공통 스테이지 배경

일반 12개와 튜토리얼 10개의 플레이 배경을 `assets/stage_background.png`로 통일한다.
일시정지·클리어는 같은 플레이 화면 위에 창을 겹치므로 새 배경이 함께 표시된다.
첫 화면·분류 선택·스테이지 목록·여행 완료 화면은 각각 기존 이미지를 사용한다.

사용자가 제공한 게임 화면에서 내장 imagegen으로 배경만 정리하고, 전체 스테이지
미리보기를 확인받은 이미지다. 설산·분홍 구름·바다와 오른쪽 햇빛·아래 양옆의
얼음 장식을 유지하고, 원본의 UI·문구·블록·가시·공·이글루는 제거하도록 요청했다.
실제 게임의 지형·캐릭터·수집물·아이템·UI는 기존 데이터에서 그린다.

이미지는 초기화 시 한 번만 불러온다. 1600×832 논리 화면을 비율을 유지해 채우고
아주 조금 남는 가장자리는 가운데 기준으로 자른다. 프레임마다 이미지 파일을
읽거나 배경을 다시 확대하지 않는다. 게임 창 크기 변경은 기존 논리 화면 변환을
그대로 사용하며 맵의 좌표·이동 범위·충돌과 물리 값은 변경하지 않는다.
