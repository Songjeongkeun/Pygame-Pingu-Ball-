# 이동 끝 표시와 장애물 및 아이템 외형

승인된 시안에 따라 다음 네 가지 변경을 적용했다. 기획서 DOCX와 원본 스테이지
배치는 수정하지 않았다.

이동 발판이 있는 일반 3·4·6·7·8·12번, 튜토리얼 3·4번의 9개 경로에서,
실제 이동 데이터로 총 32칸의 끝 표시를 계산한다. `World.movement_endpoints`는
501·508 장치의 기본 좌표와 이동 거리, 실제 가로세로 크기에서 도출하며
수동으로 남아 있는 문서 표시는 렌더링에 사용하지 않는다. 한 칸짜리 발판은
한 칸씩, 연결된 두 칸과 세 칸짜리 발판은 전체 모양을 양끝에 표시한다.
끝 표시는 충돌 없는 반투명 점선과 원이며 모든 맵에서 같은 스타일을 사용한다.
가로·세로 경로 안내선은 제거했다.

상하 이동 블록은 기본 블록과 같은 불투명도 기준으로 그림 몸체를 잘라 64×64px에
맞춘다. 충돌 크기는 원래도 64×64px이며 이동 범위·속도·위상은 그대로다.

바다사자는 기본 크기 56px와 진행 속도를 유지하고, 각 변의 바깥으로 중심을 8px
옮겼다. 블록 뒤에 그리므로 일부 몸은 가려지고, 보이는 머리와 몸통은 늘어난다.
접촉 다각형은 옮겨진 그림 중심에서 계산하되 실제 발판 외곽선에서 잘라
가려진 몸이 블록 안쪽에서 실패를 일으키지 않게 한다. 일반 11·12번과
튜토리얼 9번에 적용한다.

`assets/assets_v2/winter_cartoon/item_dash.png`와 `item_jump.png`는
바운스볼_게임기획서_v04.docx 5절 그림 1의 아이템을 기준으로 내장 imagegen을
통해 준비한 승인 이미지다. 청록색 또는 금색 결정, 흰 테두리의 남색 화살표,
눈 모자와 작은 결정을 유지하고 배경·문구·표·핑구 공은 제외하도록 요청했다.
각 PNG의 불투명 몸체를 비율을 유지해 투명 정사각형에 배치하고, 원본에서 실제
표시 크기로 한 번만 축소한다. 기존 단순 다각형 아이콘 코드는 제거했다.
아이템의 48×48px 크기, 위치, 수집 판정과 사용 입력, 획득 후 핑구 공 색상은 유지한다.

검증은 실제 발판이 방향을 바꾸는 시각의 `rect_at`과 끝 표시의 일치,
상하 블록의 64×64px 불투명 몸체, 네 방향 바다사자의 8px 노출과 지형 안쪽 판정 제외,
아이템의 비율·투명도와 기존 수집·사용 흐름을 검사한다.
