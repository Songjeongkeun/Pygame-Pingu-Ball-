# 강화학습 맵 10개

승인된 `output/rl_transfer_2to3_maps_20261031/layouts.json`에서 맵 배치를 가져왔다.
이후 요청에 따라 이 10개 맵의 좌우·상하 이동 블록 속도만 원본의 1.5배로 올렸다.
좌우 속도는 32·36·40px/s에서 48·54·60px/s로, 상하는 32px/s에서 48px/s로 바뀌었다.
이동 거리·시작 위상·블록 크기·타일 배치는 유지한다.
각 코스는 2~3층으로 구성되며 파괴·점프·좌우 이동·상하 이동·시간 블록을 포함한다.
생선·생선뼈·별·아이템은 없고 제한 시간은 180초다. 기존 게임 물리 설정을 사용한다.

`layouts.json`은 실행용 배치이며 맵 묶음 식별자는 `tutorial-five-2to3-20261031-v1`이다.
`map_01.png`부터 `map_10.png`는 목록에서 사용하는 실제 맵 썸네일이다.
메뉴와 게임 실행에는 `output` 폴더나 `tools` 모듈이 필요하지 않다.
클리어 경로·정답 행동·검증용 체크포인트는 실행용 데이터에 추가하지 않았다.

기록은 저장 파일의 `rl_records`에 맵 번호별 최단 시간으로 저장한다.
기존 일반 캠페인의 잠금 해제와 튜토리얼 기록은 별도로 유지한다.
