# Pingu Ball

주신 게임 기획서와 핑구 얼굴 사진을 바탕으로 만든 **Pygame 데스크톱 게임**입니다. 남극 배경에서 자동으로 튀는 핑구 공을 움직여 이글루로 돌아갑니다.

## 실행

Mac에서는 **`Pingu Ball 실행.command`를 더블 클릭**하세요. 이 작업 환경에는 프로젝트 전용 `.venv`와 Pygame 2.6.1을 설치해 두었습니다.

터미널에서는 프로젝트 폴더에서 실행합니다.

```sh
.venv/bin/python main.py
```

다른 컴퓨터에서 처음 실행할 때는 Python 3.10 이상을 설치하고 다음 순서로 준비합니다. Python 3.12 환경에서 검증했습니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Windows에서는 가상환경 Python 경로를 `.venv\Scripts\python.exe`로 바꾸면 됩니다.

## 조작

| 조작 | 동작 |
|---|---|
| 왼쪽·오른쪽 방향키 | 좌우 가속 이동. 공중에서도 조작 가능 |
| 방향키 놓기 | 감속 후 정지 |
| 좌우 동시 입력 | 무입력으로 처리 |
| R | 확인 없이 처음부터 다시 시작 |
| 화면 버튼 | 일시정지, 스테이지 선택, 재도전, 다음 스테이지, 종료 |

점프 키는 없습니다. 일반 발판에 내려와 착지하면 자동으로 튑니다. 스테이지 진입 직후에는 대기하며 **첫 좌우 입력에 공, 이동 발판, 블록 타이머와 기록 시간이 함께 시작**합니다. 창의 포커스를 잃으면 자동으로 일시정지합니다.

## 스테이지와 점수

튜토리얼과 일반 스테이지 7개가 있습니다. 앞 스테이지를 어떤 등급으로든 클리어하면 다음 스테이지가 열립니다. 해금한 맵은 언제든 재도전할 수 있습니다.

일반 스테이지에는 금색 생선 3개와 보라색 생선 가시 1개가 있습니다. 생선 가시는 수집 시 −1점인 아이템이며, 닿으면 실패하는 얼음 가시와 구별됩니다. 수집물의 표시 크기는 모두 14px이고 판정 영역은 중심 기준 14×14px입니다. 공의 중심이 이 영역에 들어올 때만 획득합니다.

```text
최종 점수 = 도착 기본점수 7 + 생선 개수 − 생선 가시 개수
```

| 점수 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|
| 등급 | B | A | S | SS | SSS |

생선을 하나도 먹지 않아도 클리어할 수 있습니다. 높은 선택 경로에는 생선 3개를 모아 10점을 얻는 길이 있습니다. 튜토리얼의 생선 1개는 선택 사항이고, 등급이나 점수 없이 완료 여부와 최단 완료 시간만 저장합니다.

일반 스테이지는 점수가 높은 기록을 우선하며, 동점이면 시간이 짧은 기록을 유지합니다. 실패한 도전은 최고 기록에 저장하지 않습니다. 저장 위치는 `save_data/progress.json`입니다. 손상된 저장 파일은 게임을 중단시키지 않고 안내 메시지를 표시합니다.

## 블록

| 요소 | 동작 |
|---|---|
| 일반 얼음 | 공 중심이 60px 상승하도록 자동 반동 |
| 금 간 얼음 | 첫 착지 0.5초 뒤 파괴. 떠나도 타이머 유지 |
| 분홍 점프대 | 공 중심이 90px 상승하도록 반동 |
| 파랑 왕복 발판 | 100px/s로 지정 구간 왕복. 공을 따라오게 하거나 속도를 전달하지 않음 |
| 청록 시간 발판 | 설정된 주기로 등장·소멸. 소멸 0.5초 전 점멸, 비활성 상태는 윤곽만 표시 |
| 빨간 스위치 | 첫 착지 시 A 다리 활성화. 수평 영역에서 공 전체가 벗어난 뒤 재착지하면 비활성화 |
| 보라 수평 발사 블록 | 화살표 방향 300px/s 발사, 수직 속도 0·중력 해제. 좌우 입력이나 벽·천장 충돌로 해제 |
| 얼음 가시 | 40×20px 안의 삼각형 2개. 접촉하면 실패 |
| 이글루 | 20×20px 도착 영역에 공 중심이 들어오면 클리어 |

깨지는 발판 때문에 돌아올 길이 사라져도 별도의 자동 실패 판정을 추가하지 않습니다. 필요하면 R이나 재시작 버튼을 사용하세요. 가시 접촉·화면 하단 이탈·해소할 수 없는 끼임은 즉시 처음부터 다시 시작합니다.

## 물리 설정

논리 화면은 **1200×600**, 블록은 **20×20px**, 공 반지름은 **4.5px**입니다. 창 크기를 바꾸면 전체 화면을 같은 비율로 확대·축소하고 여백을 둡니다. 카메라는 스크롤하지 않습니다.

`pingu_ball/config.py`에서 물리 설정을 조절할 수 있습니다. 비행시간을 바꾸면 중력·반동 속도·최대 수평 속도를 자동 재계산합니다.

| 설정 | 값 |
|---|---:|
| 기본 비행시간 | 0.8초 |
| 중력 | 750px/s² |
| 일반 반동 속도 | −300px/s |
| 점프대 반동 속도 | 약 −367.423461px/s |
| 최대 수평 속력 | 300px/s |
| 입력 가속도 | 3,000px/s² |
| 무입력 감속도 | 4,500px/s² |
| 물리 계산 | 120Hz, 렌더링과 분리 |

최대 속도로 이륙해 같은 높이에 돌아오면 기본 240px, 점프대 약 293.94px를 이동합니다. 정지 출발에서 계속 입력하면 기본 비행 중 약 225px 이동합니다. 위치와 속도는 소수점입니다. 공과 직사각형·삼각형의 이동 경로를 검사하고, 직선 윗면 충돌 시각은 가속도 식으로 보정합니다.

## 기획서의 미정 항목을 적용한 기준

사용자 확인에 따라 **공과 왕복 발판은 독립 이동**으로 확정했습니다. 공중 추종과 발판 속도 전달은 적용하지 않습니다. 수평 최대 속력은 맵 좌표 기준입니다.

나머지 미정 항목은 다음 기준으로 구현했습니다.

- 시작은 첫 좌우 입력이며, 초기 공 중심은 첫 발판 윗면보다 64.5px 위, 초기 수직 속도는 0입니다.
- 특수 블록의 규칙이 일반 자동 반동보다 우선합니다.
- 수평 발사 중 벽·천장에 닿으면 발사를 해제하고 중력을 다시 적용합니다. 해제 시 기존 수평 속도는 입력 가속·감속으로 이어집니다. 좌우 동시 입력은 해제 입력으로 인정하지 않습니다.
- 발사 해제 직후 같은 발사 블록에서 즉시 다시 발사되지 않도록, 공 전체가 원래 블록의 수평 영역을 벗어날 때까지 원래 발사 블록의 충돌을 임시 제외합니다. 다른 블록의 충돌은 유지합니다.
- 모서리에서 공의 원형 충돌 법선이 충분히 위쪽을 향하고 하강 중이면 착지로 인정합니다. 블록 옆면 접촉에는 반동이 없습니다.
- 겹침을 반복 보정해도 해소하지 못하는 상태가 0.05초 지속되면 끼임 실패입니다. 시간 블록 생성 순간 해소 불가능한 압착은 즉시 실패합니다. 단순히 벽 앞에서 멈추거나 제자리에서 반동하는 것은 실패가 아닙니다.
- 같은 시각의 이벤트는 실패 → 수집물 획득 → 도착 순서로 처리합니다.
- 마지막 스테이지 결과 화면에서 여행 완료 화면으로 이동할 수 있습니다.
- 웹 실행은 제공하지 않으며, 요청하신 Pygame 데스크톱 실행을 적용했습니다.

## 검증

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pingu_ball.validate --output validation_routes.json
```

`validate`는 화면 없이 실제 게임 시뮬레이션에 방향키 입력을 공급합니다. 8개 맵 각각의 무수집 클리어와 모든 생선 획득 경로를 검사하며, 실패가 하나라도 있으면 종료 코드 1을 반환합니다. 좌표를 순간 이동하거나 블록·점수를 우회하는 검증이 아닙니다.

화면을 띄우지 않는 렌더링 검사와 실제 게임 실행도 지원합니다.

```sh
.venv/bin/python main.py --headless --stage 7 --screenshot stage7.png
.venv/bin/python main.py --stage 0
```

`--stage`는 개발용 직접 진입이며 해금 정보를 변경하지 않습니다. 일반 메뉴에서는 잠긴 스테이지에 들어갈 수 없습니다. `--headless`는 별도 임시 저장소를 사용해 사용자 기록을 변경하지 않습니다.

## 파일 구성

- `main.py`: 실행 진입점
- `pingu_ball/app.py`: Pygame 화면, 버튼, 소리, 게임 루프
- `pingu_ball/engine.py`: 화면 없는 게임 물리와 상태 전이
- `pingu_ball/geometry.py`: 원·블록·삼각형 연속 충돌 검사
- `pingu_ball/levels.py`: 8개 스테이지와 검증용 입력 경로
- `pingu_ball/config.py`: 공간·물리 설정
- `pingu_ball/storage.py`: 해금과 최고 기록 저장
- `tests/test_game.py`: 물리, 충돌, 특수 블록, 저장과 경로 검사
- `assets/`: 남극 배경과 핑구 이미지
- `docs/요구사항_대응표.md`: 기획서 요구사항과 구현 위치

배경과 핑구 투명 이미지의 생성 방식과 프롬프트는 `assets/README.md`에 기록했습니다. 기획서 원본과 이전 디자인 자료는 변경하지 않았습니다.
