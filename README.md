# Pingu Ball

바운스볼 게임 기획서 v02를 반영한 Python/Pygame 게임입니다. 핑구 공을 좌우로 움직여 이글루에 도착하세요. 튜토리얼과 일반 스테이지 7개가 있습니다.

## 적용한 맵 이미지

제작한 맵 이미지 6개를 스테이지 1~6의 실제 충돌 지형으로 적용했습니다. 남극 배경과 `assets/assets_v2/winter_cartoon/`의 블록·공·이글루 이미지를 사용합니다. 원본 미리보기는 `assets/maps/stage_01.png`~`stage_06.png`에 보관하며 스테이지 선택 화면에도 표시합니다.

| 스테이지 | 이름 | 주요 동선 |
|---|---|---|
| 1 | 빙하 협곡 | 위쪽 길을 건넌 후 두 발사 블록으로 하강, 왼쪽 아래 도착 |
| 2 | 얼음 장벽 | 장벽 사이로 하강 후 오른쪽 점프 발판을 따라 상승 |
| 3 | 갈림길의 시간 | 오른쪽 계단 하강, 중앙 점프 발판을 거쳐 중앙 시간 블록 위 도착 |
| 4 | 시간의 디딤돌 | 아래쪽으로 오른쪽까지 이동 후 위쪽 길을 따라 왼쪽으로 복귀 |
| 5 | 가시 사이 왕복 | 위쪽 이동 발판으로 오른쪽 이동, 아래쪽 발판으로 왼쪽 아래 복귀 |
| 6 | 두 빙벽의 틈 | 왼쪽 상승, 장벽 사이로 하강, 이동 발판으로 오른쪽을 돌아 중앙 도착 |

현재 물리에서 건널 수 없는 일부 간격은 접근 발판을 추가하거나 위치를 조정했습니다. 이동 발판에는 양방향 화살표(↔)를 표시합니다. 6번 맵 하단의 양 끝 표시는 이동 범위이며, 표시 자체에는 충돌 판정이 없습니다. 생선은 요청에 따라 1~6번 맵에 배치하지 않았습니다. 튜토리얼과 기존 7번 맵의 지형은 유지합니다.

## 실행

특수블록 시안 A의 **37종 기능**을 추가했습니다. 스테이지 선택 화면의
**특수블록 실험실**에서 종류별로 시험할 수 있습니다. `special_blocks_play.bat`로
바로 열거나 `python main.py --lab`을 실행하세요. 번호별 직접 실행은
`python main.py --special 405`처럼 사용합니다. 실험실은 캠페인 기록을 변경하지 않습니다.
연결 방법, 장치별 기본값과 맵 작성 API는 [특수블록 문서](docs/special_blocks.md)에 있습니다.

단독 실행파일은 `output/executable/PinguBall.exe`입니다. Python 설치 없이 더블 클릭하여 실행할 수 있으며, 기록은 실행파일 옆의 `save_data/progress.json`에 저장됩니다.

Python 3.10 이상에서 프로젝트 폴더를 열고 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Windows에서는 설치 후 `Pingu Ball 실행.bat`를 더블 클릭해도 됩니다. macOS/Linux에서는 가상환경 실행 경로를 `.venv/bin/python`으로 바꾸세요.

Windows 실행파일을 다시 빌드하려면 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
& .\tools\build_exe.ps1
```

## 조작과 규칙

실패하면 `assets/audio/fail_noot.mp3`의 첨부 음성이 재생됩니다. 소리를 끄면 음성도
재생하지 않으며, 빠른 연속 실패에서는 이전 음성을 멈추고 새 음성을 재생합니다.

- 첫 화면은 제공된 `assets/title_screen.png`를 비율을 유지해 표시합니다. 이미지의 **게임 시작** 버튼을 클릭하거나 Enter·Space를 누르면 스테이지 선택으로 이동합니다. 선택 화면의 **메인 화면** 버튼이나 Esc로 첫 화면에 돌아갑니다.
- 왼쪽·오른쪽 방향키: 공중에서도 좌우 가속 이동. 놓으면 감속하며 동시 입력은 무입력입니다.
- R 또는 재시작 버튼: 확인 없이 처음부터 재시작합니다.
- 일시정지·스테이지 선택·종료: 마우스로 클릭합니다. 창의 포커스를 잃으면 일시정지합니다.
- 맵에 들어가거나 재시작하면 입력 없이 자동 반동과 모든 타이머가 진행됩니다.
- 생선은 선택 사항입니다. 공 중심이 이글루에 들어가면 즉시 정지하고 결과를 표시합니다.
- 가시 접촉·낙하·해소되지 않는 끼임은 즉시 재시작합니다. 끊긴 길은 수동 재시작합니다.

현재 1~6번 맵은 생선 없이 클리어하며 기본 7점을 받습니다. 7번 맵에는 선택 생선 3개와 생선 가시 1개가 있으며 각각 도전당 한 번만 획득합니다. 무수집 경로와 생선 가시를 피하는 전체 수집 경로를 검증합니다.

`최종 점수 = 7 + 생선 개수 − 생선 가시 개수`

| 점수 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|
| 등급 | B | A | S | SS | SSS |

튜토리얼에는 선택 생선 1개가 있으며 완료 여부만 저장합니다. 일반 맵은 점수가 높을수록, 동점이면 시간이 짧을수록 좋은 기록입니다. 낮은 등급으로 클리어해도 다음 맵이 열립니다. 실패한 기록은 저장하지 않습니다.

기록은 `save_data/progress.json`에 저장합니다. 기존 버전의 정상적인 기록과 해금 정보를 읽으며, 튜토리얼 기록은 완료 여부로 변환합니다. 손상된 파일은 안내 후 새 기록으로 시작합니다.

## 물리와 블록

### 1회용 더블 점프 아이템

튜토리얼과 모든 스테이지에 **파랑 » 앞으로 점프**와 **노랑 ↑↑ 위로 점프** 아이템을 하나씩 배치했습니다. 아이템은 32×32px이며 공 중심이 아이템 영역에 들어가면 획득합니다. 한 번에 하나만 보유하고, 이미 보유 중이면 다른 아이템은 맵에 남습니다. 점수에는 영향을 주지 않습니다.

- 획득하면 공이 제공된 `assets/ball_charged.png` 이미지로 바뀝니다. 사용 즉시 기존 공 이미지로 돌아옵니다.
- 게임 화면의 같은 위치를 **0.3초 이내에 두 번 클릭·터치**하면 1회 사용합니다. UI 버튼, 화면 밖, 일시정지 중 입력은 사용으로 처리하지 않습니다.
- 앞으로 점프는 **두 번째로 누른 위치가 공의 왼쪽인지 오른쪽인지**에 따라 방향을 정합니다. 수직 속도를 일반 점프 속도로 초기화하고, 0.3초 동안 해당 방향으로 약 426.67px/s 도약합니다. 이후 일반 이동으로 돌아옵니다. 벽이나 천장에 부딪히거나 착지하면 전진 가속이 끝납니다.
- 위로 점프는 누른 쪽과 관계없이 수직으로 다시 도약합니다. 시작 수평 속도는 0이며 높이는 현재 위치에서 최대 192px입니다. 이후 방향키로 공중 이동할 수 있습니다.
- 공중에서도 사용할 수 있습니다. 사용한 아이템은 해당 도전에서 다시 나오지 않으며, 재시작·실패 후에는 두 아이템 모두 복원되고 보유 상태는 비워집니다.

터치스크린의 손가락 입력과 일반 마우스 입력을 처리하며, 터치에서 함께 발생하는 마우스 이벤트는 중복 사용으로 세지 않습니다.

### 기본 물리

논리 화면은 1600×832px입니다. 1~6번 맵의 물리 공간은 1600×960px(25×15칸), 튜토리얼과 7번 맵은 1600×832px입니다. 블록은 64×64px, 공 지름은 28px입니다. 전체 지형을 상단 조작 UI와 하단 안내 사이에 비율을 유지해 표시하며 창 크기 변경에도 같은 물리 좌표를 사용합니다.

| 항목 | 값 |
|---|---:|
| 일반 반동 높이 / 왕복 시간 | 96px / 0.9초 |
| 점프대 높이 / 왕복 시간 | 144px / 약 1.10227초 |
| 중력 | 약 948.148148px/s² |
| 일반 / 점프대 이륙 속도 | 약 −426.666667 / −522.557812px/s |
| 최대 수평 속력 | 약 213.333333px/s |
| 입력 가속 / 무입력 감속 | 9600 / 14400px/s² |
| 왕복 발판 속력 (최초 대비 3배) | 약 213.333333px/s |
| 발사 블록 속력 (최초 대비 3배) | 640px/s |
| 물리 / 화면 갱신 | 120Hz / 목표 60FPS |

반동은 기존 낙하 속도를 반전하지 않고 지정된 이륙 속도로 교체합니다. 일반 최대 속도 출발은 192px, 정지 출발은 약 189.63px, 점프대 최대 속도 출발은 약 235.15px를 이동합니다. 물리와 타이머는 초 단위이며 일시정지 시간은 기록에서 제외합니다.

| 블록 | 동작 |
|---|---|
| 금 간 얼음 | 첫 윗면 착지 0.5초 후 파괴. 떠나도 타이머 유지 |
| 분홍 점프대 | 144px 반동. 천장 여유 172px 이상 확보 |
| 양방향 이동 발판 | 64×64px 여러 개가 같은 위상으로 왕복. 5번 맵은 위쪽 17칸·아래쪽 18칸, 6번 맵은 18칸 이동. 이동량·속도를 공에 전달하지 않음 |
| 시간 블록 | 1~6번 맵은 5.2초 중 4.2초 활성, 블록별 시작 위상 적용. 마지막 맵은 3.2초 중 2.2초 활성 |
| 빨간 스위치 | 착지 시 연결 다리를 전환. 공 전체가 수평 영역 밖으로 나간 뒤 재착지해야 다시 전환 |
| 발사 블록 | 윗면 착지 시 공 중심을 블록의 세로 중심 높이에 맞춘 뒤 화살표 방향으로 640px/s 발사, 수직 속도 0·중력 해제. 방향키로 해제하면 일반 수평 속력으로 전환 |
| 가시 | 새 맵은 64×64px 타일에 위쪽 가시 48px와 하단 받침 16px. 기존 7번 맵은 128×64px 영역의 삼각형 2개 |

## 기획서의 미정 항목에 적용한 기준

- 기존 프로젝트의 Python/Pygame 데스크톱 실행과 별도 무화면 학습 구조를 유지합니다.
- 생선·생선 가시의 표시 폭과 중심 판정 영역은 모두 32px / 32×32px입니다. 금색 생선과 보라색 뼈 모양으로 구별합니다.
- 이글루 전체 64×64px가 비고체 도착 영역입니다.
- 공 전체가 해당 맵의 아래 경계를 벗어나는 `중심 y − 14 > 맵 높이`에서 낙하 실패합니다. 좌우·위쪽은 벽입니다.
- 공이 위에서 하강하며 평평한 윗면에 닿았을 때만 자동 반동과 착지 효과를 적용합니다. 옆면은 벽 방향의 수평 이동만 막고 수직 속도와 중력은 유지합니다. 아랫면은 상승 속도를 0으로 만듭니다. 윗면 범위 밖의 모서리는 옆으로 분리하며 자동 반동하지 않습니다. 벽을 계속 눌러도 남은 물리 시간의 이동·중력·충돌 검사를 모두 진행합니다.
- 시간 블록은 소멸 0.5초 전에 깜빡이며 비활성 중에는 반투명 윤곽만 표시합니다. 스위치의 비활성 연결 블록은 보이지 않습니다.
- 발사 제한시간은 없습니다. 어느 한 방향키 입력 또는 벽·천장 충돌로 발사를 해제합니다. 동시 입력은 해제하지 않습니다. 발사 시작부터 공 전체가 원래 발사 블록의 수평 영역을 벗어날 때까지 해당 블록만 충돌에서 제외합니다. 다른 블록과 가시의 판정은 유지합니다.
- 겹침 보정으로도 해소되지 않는 압착이 0.05초 지속되면 실패합니다. 시간 블록 생성 직후 해소 불가능한 압착은 즉시 실패합니다.
- 동일 시각의 충돌은 실패 → 수집 → 도착 순서입니다. 재시작 시 눌려 있던 방향키 상태를 비우므로 다시 눌러 이동합니다.
- 마지막 맵 결과에서 여행 완료 화면으로 이동합니다.

## 검증과 무화면 학습

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pingu_ball.validate
.\.venv\Scripts\python.exe main.py --headless --stage 6 --frames 60 --screenshot stage6.png
```

검증기는 실제 물리 엔진에 방향키 입력만 공급해 8개 맵의 무수집·전체 수집 경로 16개를 재생합니다. `--output 파일.json`으로 결과를 저장할 수 있습니다. `--headless` 실행은 별도 임시 저장소를 사용합니다. `--stage 0`~`7`은 개발용 직접 진입이며 일반 선택 화면의 잠금 규칙에는 영향을 주지 않습니다.

Pygame 없이 학습할 때는 다음 API를 사용합니다.

```python
from pingu_ball.environment import Environment

env = Environment(stage=1)  # 새 맵 기본 120초, 튜토리얼·7번 맵 60초
observation, info = env.reset()
observation, reward, terminated, truncated, info = env.step(1)
# 보유한 아이템을 왼쪽으로 사용하면서 한 틱 진행 (위로 점프는 방향 무시)
observation, reward, terminated, truncated, info = env.step(0, use_power=True, power_direction=-1)
```

행동은 `-1`(왼쪽), `0`(무입력), `1`(오른쪽)이며 한 번에 물리 1틱을 진행합니다. 관측에는 맵 크기, 공의 위치·속도, 이전 입력, 발사 상태, 생선의 위치·가치·획득 여부, 가시의 영역·삼각형, 도착 영역, 스위치, 블록의 위치·이동 범위·방향·타이머·연결 그룹이 포함됩니다. 관측은 JSON으로 직렬화할 수 있는 데이터입니다. `time_limit`을 명시하면 학습 제한시간을 직접 지정할 수 있습니다.

보상은 생선 +1, 생선 가시 −1, 성공 +7, 실패 −7이며 같은 단계의 보상은 합산합니다. 일반 이동과 제한시간 종료 보상은 0입니다. 성공·실패는 `terminated`, 제한시간은 `truncated`로 구분하며 `info['reason']`에 성공·실패 사유·시간 초과를 반환합니다. 종료 상태를 먼저 전달하고, 이후 `reset()`을 호출하면 공·수집물·블록·타이머·스위치·이전 입력을 초기화해 다음 도전을 시작합니다. AI 학습에서는 화면과 기록 파일을 사용하지 않습니다.

- `pingu_ball/app.py`: Pygame 화면·입력·소리·고정 간격 게임 루프
- `pingu_ball/config.py`: 물리 기준과 계산식
- `pingu_ball/engine.py`, `geometry.py`: 화면과 독립된 게임 상태·연속 충돌
- `pingu_ball/levels.py`: 타일 기반 맵과 검증 경로
- `pingu_ball/reference_levels.py`: 이미지 기반 스테이지 1~6의 배치와 왕복 구간
- `pingu_ball/skin.py`: 공통 겨울 이미지와 양방향 이동 블록 렌더링
- `pingu_ball/route_driver.py`: 일반 방향키 입력으로 이동 발판 탑승·하차 경로 검증
- `pingu_ball/storage.py`: 최고 기록·해금 저장
- `pingu_ball/environment.py`: 학습용 reset/step
- `pingu_ball/validate.py`, `tests/`: 경로·물리·UI 회귀 검증
- `assets/`: 남극 배경, 겨울 테마 이미지, 맵 원본 미리보기
